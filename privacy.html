Политика конфиденциальности

Дата: 24 ноября 2026 года.

Личное подключение использует rclone и Google Drive API для доступа к файлам Google Диска, выбранным владельцем учётной записи, и обмена ими с его компьютером. Доступ выполняется с разрешения владельца через Google OAuth.

Учётные данные подключения хранятся в локальной конфигурации rclone на компьютере владельца. Эта веб-страница не собирает данные Google, не содержит форм и не передаёт данные между браузером и приложением.

Владелец может отозвать доступ через настройки безопасности своего аккаунта Google. Использование данных Google подчиняется политике данных пользователей Google API Services, включая требования Limited Use.

По вопросам обратитесь к владельцу через профиль GitHub.
